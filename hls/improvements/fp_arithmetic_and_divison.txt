Summary of changes

The bilateral filter datapath was rewritten to remove all 
IEEE floating-point arithmetic from the per-pixel computation. 
All Gaussian weights (spatial and color) are now precomputed 
offline and stored as fixed-point lookup tables (weight_t), 
and the main accumulation uses ap_ufixed types (wsum_t for 
weight sums and vsum_t for weighted value sums). Per-tap 
floating-point multiplies were replaced by fixed-point 
multiplies and additions, and the obsolete floating-point 
Gaussian data header was removed entirely. This ensures the 
core convolution loop consists only of fixed-point arithmetic, 
enabling predictable synthesis and significantly reduced DSP/LUT 
usage.

The expensive floating-point division used for normalization 
was replaced with a reciprocal-LUT-based normalization step. 
The accumulated weight sum is rounded in fixed point, quantized 
to an index, and used to fetch a precomputed reciprocal 
(RECIP_LUT), after which normalization is performed via a 
fixed-point multiply. This eliminates hardware dividers and 
floating-point units while preserving visually acceptable output. 
The AXI-stream interface, buffering logic, and output packing 
remain unchanged, maintaining functional compatibility while 
meeting the acceptance criteria of no floating-point operators 
in the synthesized datapath.
